# 🏦 Агрегатор новостей банков (`global_parser_project`)

Интерактивное веб-приложение на базе **FastAPI**, которое выполняет автоматический сбор, хранение и безопасное отображение актуальных новостей банков (**Газпромбанк** и **Банк Русский Стандарт**) с разграничением прав доступа пользователей по ролям.

---

## ⚙️ Логика работы приложения

1. **Аутентификация пользователей:** Пользователь вводит логин и пароль через форму авторизации (`entrance.html`). Модуль `cipher.py` проверяет существование пользователя и сравнивает SHA-256 хэш введённого пароля с данными, хранящимися в базе SQLite.

2. **JWT-авторизация и RBAC:** После успешной проверки создаётся защищённый **JWT-токен** (срок действия — **10 минут**), содержащий информацию о разрешённом маршруте (`/gazprombank`, `/rsb` или `/all`). Благодаря этому реализовано разграничение прав доступа (**Role-Based Access Control**).

3. **Отображение данных:** Защищённые эндпоинты в `main.py` проверяют токен, получают соответствующие новости из базы данных и динамически отображают их пользователю с помощью шаблонизатора **Jinja2**.

4. **Сбор новостей:** Модуль `parsing_main.py` координирует работу парсеров, которые получают актуальные новости с официальных сайтов банков, обрабатывают даты публикации, очищают текст и сохраняют результаты в SQLite.

---

## 🛠 Стек технологий

* **Язык:** Python
* **Веб-фреймворк:** FastAPI, Uvicorn, Jinja2Templates, FastAPI StaticFiles
* **Парсинг:** Requests, Beautiful Soup 4, fake-useragent, dateparser, transliterate
* **База данных:** SQLite, sqlite3
* **Безопасность:** PyJWT, hashlib (SHA-256), python-dotenv
* **Валидация:** Pydantic
* **Frontend:** HTML5, CSS3 (Flexbox), JavaScript

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/username/global_parser_project.git
cd global_parser_project
```

### 2. Создание и активация виртуального окружения

```bash
python -m venv venv
```

* **Windows (PowerShell):**

```powershell
.\venv\Scripts\Activate
```

* **macOS / Linux:**

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации (.env)

Создайте файл `.env` в корневой директории проекта и добавьте секретный ключ для генерации JWT-токенов:

```env
Sekret_Key=ваш_секретный_ключ_безопасности
```

### 5. Запуск приложения

```bash
uvicorn main:app --reload
```

После запуска приложение будет доступно по адресу:

```
http://127.0.0.1:8000
```
