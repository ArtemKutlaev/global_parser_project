# 🏦 Агрегатор новостей банков (`global_parser_project`)

Интерактивное веб-приложение на базе **FastAPI**, предназначенное для автоматического сбора, хранения и безопасного отображения актуальных новостей банков **Газпромбанк** и **Банк Русский Стандарт** с разграничением прав доступа пользователей (RBAC).

---

## 📖 Описание проекта

Приложение автоматически собирает новости с официальных сайтов банков, сохраняет их в базе данных SQLite и предоставляет доступ к ним через веб-интерфейс.

После авторизации пользователи получают доступ только к тем разделам, которые разрешены их ролью.

---

## ⚙️ Логика работы

### 1. Аутентификация

Пользователь вводит логин и пароль через страницу `entrance.html`.

Модуль `cipher.py`:

- проверяет существование пользователя;
- вычисляет SHA-256 хэш введённого пароля;
- сравнивает его с сохранённым в базе SQLite.

---

### 2. JWT-авторизация и RBAC

После успешной авторизации создаётся JWT-токен сроком действия **10 минут**.

Токен содержит информацию о разрешённом маршруте:

- `/gazprombank`
- `/rsb`
- `/all`

Благодаря этому реализовано разграничение прав доступа (**Role-Based Access Control**).

---

### 3. Отображение новостей

Защищённые маршруты FastAPI:

- проверяют JWT-токен;
- получают необходимые новости из SQLite;
- отображают их через шаблоны **Jinja2**.

---

### 4. Парсинг новостей

Модуль `parsing_main.py` запускает парсеры, которые:

- получают новости с официальных сайтов банков;
- очищают HTML;
- обрабатывают даты публикации;
- сохраняют данные в SQLite.

# 🚀 Установка и запуск

## 1. Клонирование репозитория

```bash
git clone https://github.com/username/global_parser_project.git
cd global_parser_project
```

---

## 2. Создание виртуального окружения

```bash
python -m venv venv
```

### Windows

```powershell
.\venv\Scripts\Activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## 4. Настройка `.env`

Создайте файл `.env` в корне проекта.

```env
Sekret_Key=ваш_секретный_ключ
```

---

## 5. Запуск приложения

```bash
uvicorn main:app --reload
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

# 🔐 Безопасность

- Срок действия токена — **10 минут**

- Секретный ключ хранится в `.env`
